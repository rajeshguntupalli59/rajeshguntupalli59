## 👨‍💻 About Me

I'm **Raj** — a **SQL Server database administrator** working at the intersection of databases and AI. I diagnose performance problems, design indexing strategies, and keep production SQL Server running under real load — increasingly with machine learning in the loop: anomaly detection on live metrics, AI-assisted query tuning, and predictive alerts that catch problems before the 2am page.

Everything I build is **self-hosted by design**. Your schema, your queries, your credentials stay on your infrastructure — that's not a feature, it's the starting requirement.
